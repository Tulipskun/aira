# Character expression images

Every character uses the same folder structure:

- Isla: `images/isla/`
- Rem: `images/rem/`
- Bocchi: `images/bocchi/`

Put expression images in the matching character folder. Optionally add a `manifest.json` in that folder with `"filename": "short usage description"` entries. Supported formats: JPG, JPEG, PNG, WebP, and GIF. A character can only select and send images from its own folder.
